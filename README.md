# Missão Aquário Digital: Protocolo de Versionamento e Gestão de Ecossistema

Este repositório contém a implementação do módulo de controle de qualidade da água, desenvolvido para monitorar e alertar sobre os níveis de pH e temperatura do ecossistema. 

## Camadas do Ambiente
O fluxo de desenvolvimento deste projeto segue um protocolo de versionamento corporativo dividido em três etapas:
* **develop:** Ambiente de desenvolvimento onde as novas funcionalidades (features) são integradas inicialmente.
* **stage:** Ambiente de testes e homologação para validação da qualidade (QA) antes do lançamento.
* **main:** Ambiente de produção, contendo apenas o código estável e aprovado para uso.
